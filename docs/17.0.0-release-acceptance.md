# V13 to V17 release acceptance

The starting point was the public, regular release `v12.9.5.7` at `6c4e8c719a9f6aa74be3228c2aa58351ea393904`. It remains reachable from the protected default branch, `main`. The final stable documentation update changed only the README and branch guide. Production installations were outside this work.

## What was tested

A single populated installation progressed through 12.9.5.7, 13.0.0, 14.0.0, 15.0.0, 16.0.0 and 17.0.0. At every step the administration entry point ran the migration and the public page displayed the new version. Checks covered the database page and stylesheet hashes, the custom reset template, CSS fetched over HTTP, uploaded content and local configuration. The explicitly enabled layout reset then published the selected standard stylesheet. Database and file backups must be treated as a pair for rollback. [Executable upgrade test](../tests/sequential-upgrade.py)

On the cumulative candidate, the disposable PHP 8.4 and MariaDB tests passed 33 save/index checks, 53 resource-activity checks and 58 large-Rename checks. They exercised real writers, background work, interruption and recovery. Killing the worker released the process lock. A blocked database attempt ended after approximately five seconds and released its locks. Full HTTP indexing completed in six requests. The GitHub regression matrix used PHP 8.3, 8.4 and 8.5. PHP 9 was not executed. The upgrade test exercised each intermediate version in order.

## Historical references and consumers

The 31 historical working branches were retired after their exact tips had been compared with the live refs and preserved in the V17 tag. Twenty-two tips had previously been outside all retained lines and tags. The archival parent retains their exclusive commits and trees. The source index records the full commit for each original name. To recover a historical working tree, fetch the V17 tag and create a local branch at the recorded commit. The application's release ancestry follows the first-parent path. [Historical source index](17.0.0-historical-branches.md)

The final check found no open pull requests targeting the retired names and no active workflows on them. Links in the maintained branch guides and affected historical reports use immutable source revisions. Public code search identified a Docker build cloning the default branch, a submodule pinned to a commit retained by main and a Docker build downloading the historical v12.7.26 tag. These references remained valid. Public code search cannot enumerate private or unpublished checkout scripts. The numbered documentation branch used for the stable guide was retired after its merge.
