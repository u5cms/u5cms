## Operation

The existing page-source textareas in both editor panes and all five language
slots gain an actions menu. Open it with a right-click on selected text or a
reference, Alt+Enter, the keyboard context-menu key or Shift+F10.
Shift+right-click retains the browser menu.
Escape closes the menu and returns to the source selection. The menu is bounded
to the editor viewport and keyboard focus stays inside it while open.

Select text to apply Bold, Italic, Underline and other supported inline/heading
formats. The actual delimiters come from this installation's `inserts` table;
the editor does not invent replacements for customized definitions. Applying
the same adjacent format to its inner selection removes that wrapper. The
original source remains an ordinary textarea, with source markup such as
`[b]text[/]` rather than a rich-text serialization.

Object actions understand `[object]`, `[$$$:object]`, `[human text:object]`,
`[:human text:object]`, labels containing colons, typed code names and query
suffixes. The object type is looked up on the authenticated backend. Every
P-object variant offers **Edit** through `../edit.php?n=OBJECT&l=LANGUAGE`,
URL-encoded in a new tab with `noopener noreferrer`. Code objects use the code
editor; other types use their existing metadata forms. Existing write endpoints
still enforce authentication, CSRF, archive/code administrator rules and revision
conflict handling.

The menu provides Edit, page Preview, Metadata, available Original/download,
Replace target, Link text, Search/correct, Uses, Copy reference and Remove
reference. Actions depend on object type and existing rights. A missing target
offers correction/search without changing the source. A typed, valid target is
accepted directly; choosing a suggestion is not required. Target replacement
preserves the label, inclusion/button prefix and query suffix. Label editing
preserves the target and cannot convert a transclusion into an ordinary link.
Removing a reference keeps an explicit label; a plain reference or transclusion
is removed entirely. Undo reverses these operations.

Formatting and reference detection avoid raw `[h:]...[:h]` blocks, HTML/code
regions, template inclusions, headings made from multiple brackets, reserved
insert tokens, nested malformed references and incomplete bracket groups.
Only the page-source fields are enhanced: login lists, metadata forms, arbitrary
form inputs and the separate code editor are not treated as page markup.

## Synchronization, recovery and limits

Every source edit, paste, format, replacement, undo and redo participates in the
existing dirty-state, peer-editor synchronization, preview and save mechanisms.
The untouched peer selection/scroll is retained when its value is synchronized.
The source snapshot is checked again before applying an asynchronous lookup
result, so stale menus cannot overwrite newer edits. Nothing is autosaved by an
object action. Navigational actions open another tab and keep the source editor.

Undo/redo records source transactions, including ordinary typing and pasted text,
per textarea. Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z and Ctrl+Y operate this history. Typing
is grouped into short transactions; actions remain separate. The history is
limited to 50 snapshots and four million UTF-16 code units including the current
source. Reloading closes that in-memory history; saved revisions remain in the
CMS's existing version history. IME composition is not intercepted by shortcuts.

Lookup/search/usage responses are authenticated, read-only, noncached JSON with
bounded queries. Search returns at most 30 matching object names. Uses checks
at most 200 candidate resources across the five languages and reports when the
candidate limit is reached; it is not an assertion that unsaved text, dynamic
PHP or every external reference was enumerated. Download links use the existing
file-access proxy. Clipboard permission failure falls back to a selected,
copyable source field. Lookup timeout/failure leaves the source intact.
