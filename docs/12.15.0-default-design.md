# 12.15.0: restrained default website design

Authorized on 31 October 2026, after the mobile-controls backport. Starting
commit: `cb876c924af9193a243e01edaacdfc773a4637c7`, the corrected cumulative
12.14.0 release. All nine mobile correction refs were verified remotely before
this work started; main remains separate.

The four distribution representations are `u5standard.sql`, `u5conference.sql`,
the published `r/*.css` files and their `r/*!css.tpl` reset baselines. The
active database C-objects are installed from the SQL seed and are the source of
later CMS publication. `tools/sync-default-css.php` updates both seeds and the
packaged exports from the reset baselines; `--check` verifies exact agreement.

The design keeps the fixed 1330px desktop layout, column widths, template,
navigation hierarchy, content, logo/banner and the existing mobile conversion.
No responsive CSS, breakpoints or replacement mobile layout are added. It
refines typography, neutral backgrounds, shadows, dividers, navigation feedback,
form controls and tables, with explicit keyboard focus styling.

This is a distribution/default-layout update. Normal upgrades preserve a site's
active custom C-objects and existing `r/` reset sources. To adopt the new default
design on an existing site, back up its paired SQL/files first, review the eight
new reset sources, and explicitly apply the normal guarded layout-reset process
or publish the chosen C-objects in the backend. Do not overwrite a customized
site's active design through an automatic migration. Roll back with the paired
backup or the CMS's retained C-object versions.
